- `make check` passes formatting, Packer validation, ShellCheck, Zsh syntax checks and 44 tests.
  Its live checks are explicitly reported as skipped; the separate live runs below supply that evidence.
- The real disposable sealing regression passes. It checks removal of build passwords, keys,
  identity and client-state residue while retaining the selected shared shell configuration.
- The installed PDS candidate passes all 25 package/helper tests in disposable Ubuntu with networking
  disabled, including real SSH authentication controls and updater lock/conffile handling.
- Actual first-user validation exposed a Zsh completion defect. The selected PDS installer/configuration
  now maps the `k` alias to kubectl's generated completion registration. The failing and passing
  regression runs are retained. The older `configure_kubectl_plugins` helper is outside this integration;
  its legacy completion mapping remains a documented limitation.
- R-18's incomplete shell checks now fail on each missing capability or failed tool. Build homes use
  an explicit allowlist, and artifact checks require the expected package source. R-19 independently
  verified those repairs and returned two nits. PDS workflow-only PR coverage is repaired; the legacy
  helper limit is documented.
- PDS check jobs use read-only tokens, discard checkout credentials and calculate versions without
  tagging. Publication remains confined to the existing main-branch release/deployment jobs. Local
  Actionlint and structured workflow-policy checks pass; hosted CI results are reported separately.
- All relative documentation links resolve. Both Mermaid diagrams render to SVG in Chromium and
  Firefox. A Bun-only attempt lacked browser DOM support and is not counted as a render.

## Limits and cleanup

Eight final fresh-instance checks and final ownership-limited cleanup are still running. Seven original
guests are protected by configuration hashes and power-state snapshots. A final audit must confirm them
and the original storage configuration after removing owned resources and temporary API identities.
Earlier failed harness attempts and the successful preliminary clone pair are retained separately;
they do not substitute for the final matrix.

The currently published PDS 0.19.0 installs through the real signed repository, but lacks the new image
helpers. That smoke test does not establish the future feature release. After owner review and separate
PDS merge/release authorization, build through the signed-repository route and record its exact release
and provenance. Until then AC-08 and full feature acceptance remain open. ARM/HVF, other storage backends,
a full Fedora restoration and an off-host backup destination are not established here.

No merge, release or website publication is part of this validation. Homelab guides stay draft.
